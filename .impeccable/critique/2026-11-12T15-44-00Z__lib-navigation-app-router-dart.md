## 디자인 고유성 판정
카테고리 아무 앱에 넣어도 성립하는 화면이다. 검정 배경, 골드 강조, 둥근 테두리 카드를 세로로 쌓는 구조가 모든 탭에서 반복된다. 배그다운 요소는 지도 타일과 이탤릭 BGMS 워드마크 정도다. 무기 사진·맵 일러스트·티어 엠블럼처럼 이미 서버에 있는 자산을 거의 쓰지 않는다. 전적 앱인데 화면의 주인공이 숫자와 사람이 아니라 카드 테두리다.

## 전체 인상
기능은 많고 실패 처리 원칙도 잘 지켰다. 하지만 정보 구조가 기능을 추가한 순서 그대로 쌓여 있다. 가장 큰 기회는 탭 구조를 5개로 다시 짜고, 홈을 "내 계정 + 오늘의 배그"로 만드는 것이다.

## 잘 된 점
- 결측 값과 실제 0을 구분하고, 실패를 숨기지 않는 데이터 원칙
- 매치 행(#순위 · 맵 · 모드 · 킬 · 딜)이 한눈에 읽히는 압축 구조
- 지도 서버 타일 품질과 전체 화면 전환

## 우선순위 문제
1. [P1] 탭 6개와 숨은 기능. 무기·메타·핫드랍·상자·가방이 2단계 안쪽에 있고, 마이가 탭 한 칸을 차지함. 해결: 5탭 재구성(홈·전적·지도·도감·커뮤니티), 마이는 홈 우상단 프로필로, 랭킹은 홈 섹션과 전적 안으로.
2. [P1] 홈과 전적 탭의 역할 중복. 둘 다 검색창 + 빈 카드. 해결: 홈은 검색 + 내 계정 카드 + 최근/즐겨찾기 + 커뮤니티 인기글 + 패치·메타 요약. 전적 탭은 "내 계정" 기본 표시로 바로 기록을 보여줌.
3. [P1] 전적 상세가 긴 한 줄 스크롤. 프로필 → 시즌 → 티어 → 레이더 → 지표 → 매치 → 버튼 5개. 스쿼드 AI까지 붙이면 더 길어짐. 해결: 고정 프로필 헤더 + 하위 탭(요약 / 매치 / AI·스쿼드 / 무기 숙련도).
4. [P1] 목록이 텍스트 덤프. 무기 도감은 사진 없이 텍스트 4줄 + 체크박스, 메타는 표. 해결: 웹과 같은 무기 이미지(/api/images/weapons/{id}.webp), 분류 탭, 상세 페이지, 비교는 별도 모드.
5. [P2] 시각 체계가 웹 이식 수준. 골드 색 불일치, iOS에서 Material 컨트롤, 헤더 형태 혼재, 11px 라벨. 해결: 새 시각 언어(DESIGN.md)를 먼저 정하고 공통 컴포넌트로 재작성.

## 작은 관찰
- 홈 Steam/Kakao 선택이 검색창 아래 오른쪽에 떨어져 있어 검색 행과 분리돼 보임
- 홈의 두 배너(지도·상자깡)가 서로 다른 스타일
- 랭킹 "최신 랭킹" 버튼과 상단 새로고침 아이콘이 같은 일을 함(웹은 새로고침 제거함)
- 무기 도감에 "접이식 방패", "박격포"가 일반 총기와 섞여 기본 피해 0으로 표시

## 기능 결함 (디자인 외)
- 지도 카테고리 설정을 서버 API가 아니라 Supabase `map_settings`에서 직접 읽음. Supabase 값이 없으면 지도 마커가 통째로 막히고, 앱에 이미 있는 `/api/maps/settings` 클라이언트를 안 씀(maps_repository.dart:43).
- 무기·차량·상자·게시판 일부도 Supabase 테이블 직접 조회.
- 통합 워크스루가 지도 단계에서 실패해 이후 화면 캡처가 갱신되지 않음.
